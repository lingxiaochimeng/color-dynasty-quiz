# 国画色 · 朝代

> 15 道题，测出你的性情最接近哪一种中国传统国画颜料色，以及与之相伴的那个朝代。

一个纯前端、零依赖的单页应用。答题结束后先给出**各颜色的得分占比环形图**，再给出得分最高的颜色色卡、以该色为主调的传世国画，以及对应朝代的代表性图像与简介。

界面只呈现颜色与朝代，**不展示任何性格描述**。

## 特性

- **零依赖、零构建**：一个 `index.html` 内含全部样式与逻辑，双击即可运行。
- **离线可用**：24 张配图全部本地化，不请求任何外部资源。
- **移动端适配**：响应式布局；占比环形图点击色块即可查看该颜色与对应朝代。
- **国画颜料色命名**：12 种颜色均取自中国传统国画颜料名（蛤白、朱砂、雌黄、墨色、赭石、胭脂、朱磦、藤黄、花青、石绿、石青、洋红）。
- **素材全为自由授权**：所有图片为 Public domain 或 CC0，可自由使用。

## 快速开始

无需安装任何依赖，直接用浏览器打开即可：

```
index.html
```

如需本地起一个静态服务器（便于手机同局域网访问）：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 部署到 GitHub Pages

1. 把 `index.html` 与 `images/` 放到仓库根目录（**不要**保留外层文件夹）。
2. 仓库 **Settings → Pages → Source** 选 `Deploy from a branch`。
3. 分支选 `main`，目录选 `/ (root)`，保存。
4. 稍后访问 `https://<用户名>.github.io/<仓库名>/`。

> 注意：GitHub Pages 的 `Deploy from a branch` 只支持根目录 `/` 或 `/docs`。若把站点放在其他子目录，请改用 GitHub Actions 部署。

## 计分与判定规则

- 共 **15 题**，每题 **4 个选项**，每个选项为其对应原型 **+2 分**。
- 累计得分最高的原型胜出。
- **并列处理**：先取第 15 题所选的原型；若仍并列，按固定顺序（夏 → 清）取前者。
- 12 个原型在题库中**各出现 5 次**，机会均等。
- 结果页的环形图按各原型的**得分占比**分片，降序排列；点击任意色块可查看该颜色与对应朝代，得分最高者外侧有标记。

## 素材与授权
